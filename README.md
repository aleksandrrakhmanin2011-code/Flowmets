# FlowMet
Первый каркас Android-приложения для метеорологии.

Уже есть:
- тёмный интерфейс;
- нижняя навигация;
- главный экран погоды;
- почасовой блок;
- недельный прогноз;
- заготовки радара, карт и настроек;
- разрешения Internet/Location.

Следующий этап: подключение реального API погоды, геолокации, карт и радара.
